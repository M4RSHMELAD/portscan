# Portscan

`portscan` — Go-пакет для проверки доступности TCP-портов. Проверка состоит из установки и немедленного закрытия TCP-соединения. Для работы достаточно стандартной библиотеки Go 1.25.5.

## Использование

```go
package main

import (
    "context"
    "fmt"
    "log"
    "net"
    "strconv"
    "time"

    "github.com/m4rshmelad/portscan"
)

func main() {
    scanner, err := portscan.New(portscan.Config{
        Concurrency:    16,
        ConnectTimeout: 500 * time.Millisecond,
    })
    if err != nil {
        log.Fatal(err)
    }

    ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
    defer cancel()

    results, err := scanner.Scan(
        ctx,
        []string{"127.0.0.1", "::1", "localhost"},
        portscan.Port(443),
        portscan.Range(8000, 8005),
    )
    if err != nil {
        log.Print(err)
        return
    }

    for result := range results {
        host := result.Host
        if result.IP.IsValid() {
            host = result.IP.String()
        }
        address := net.JoinHostPort(host, strconv.Itoa(int(result.Port)))
        fmt.Printf("%s %s %s (%s)\n", result.Host, address, result.State, result.Duration)
        if result.Err != nil {
            fmt.Println(result.Err)
        }
    }
    if err := ctx.Err(); err != nil {
        log.Print(err)
    }
}
```

Путь модуля `github.com/m4rshmelad/portscan` используется для локального подключения. Для запуска примера сохраните его как `main.go` в соседнем каталоге и выполните там следующие команды.

```sh
go mod init example.com/demo
go get github.com/m4rshmelad/portscan

go run .
```

## Публичный API

- `New(Config) (*Scanner, error)` создаёт сканер. `Concurrency` задаёт общий лимит одновременно выполняемых TCP-подключений для всех вызовов одного экземпляра. `ConnectTimeout` применяется отдельно к каждому подключению и каждому DNS-запросу. Оба параметра должны быть положительными. Дедлайн переданного контекста может сократить каждый из этих таймаутов.
- `Port(n)` выбирает отдельный порт, `Range(first, last)` — диапазон с обеими границами. В одном вызове можно передать любое сочетание портов и диапазонов. Допустимы порты от 1 до 65535. Пересечения и повторы объединяются. Пустой набор и неверные границы отклоняются.
- `(*Scanner).Scan(ctx, hosts, ports...) (<-chan Result, error)` проверяет входные данные и запускает проверки в фоне. Ошибки входных данных имеют тип `*InputError` с полями `Field`, `Index` и `Reason`. Для уже завершённого контекста возвращается его ошибка. Сетевые ошибки приходят в результатах, порядок которых зависит от времени завершения проверок.
- `Result` содержит нормализованный `Host`, адрес `IP` типа `netip.Addr`, номер `Port`, состояние `State`, время операции `Duration` и исходную ошибку `Err`. Для успешного подключения `Err == nil`. `Duration` измеряет время подключения без ожидания свободного места в очереди.

### Цели и DNS

Поддерживаются IPv4, IPv6 без квадратных скобок, IPv6 с зоной (например, `fe80::1%eth0`) и DNS-имена в ASCII, включая Punycode. Пробелы по краям удаляются. Пустой список, пустой хост, неверный IP или недопустимое DNS-имя приводят к ошибке до начала проверок. Метки DNS-имени могут содержать буквы, цифры и внутренние дефисы. Цель из одних цифр и точек должна быть корректным IPv4-адресом.

IP-адреса приводятся к каноническому виду. IPv4-mapped IPv6 без зоны приводится к IPv4. DNS-имена сравниваются без учёта регистра, при этом завершающая точка сохраняется, поскольку влияет на разрешение имени. Повторы нормализованной цели обрабатываются один раз. Разные DNS-имена и явный IP остаются самостоятельными целями, даже если указывают на один адрес.

Каждое DNS-имя разрешается один раз за вызов `Scan`. Каждый уникальный IP из ответа проверяется на каждом выбранном порту. Ошибка разрешения даёт результат по каждому порту этой цели. В таких результатах `IP.IsValid() == false`, а `Duration` содержит время DNS-операции. Проверки остальных целей продолжаются.

### Состояния

Состояние определяется по типам ошибок Go и кодам ОС.

| Состояние | Условие |
| --- | --- |
| `open` | TCP-соединение установлено. |
| `closed` | ОС сообщила, что соединение отклонено. |
| `timeout` | Истёк таймаут операции или дедлайн контекста. |
| `unreachable` | ОС сообщила, что сеть или хост недоступны. |
| `canceled` | Начатая TCP-проверка прервана явной отменой контекста. |
| `error` | Другая ошибка, например DNS-имя не найдено. |

### Параллельность и отмена

Один `Scanner` можно безопасно использовать из нескольких горутин. Пакет генерирует пары адресов и портов по мере освобождения мест для проверок. Размер буфера результатов и число ожидающих отправки горутин ограничены. Если читатель замедляется, планирование в этом вызове приостанавливается, а уже завершённые соединения освобождают места для других вызовов.

Читайте канал до закрытия. Если результаты больше не нужны, отмените переданный контекст. При отмене планирование прекращается, текущие сетевые операции завершаются, канал закрывается. Если отправка результата после отмены заблокирована, пакет может его пропустить, чтобы завершиться при остановившемся читателе. Цели и порты, до которых выполнение не дошло, результатов не дают. Для определения причины досрочного завершения проверьте `ctx.Err()`.

## Проверка

Запустите тесты с детектором гонок из корня репозитория.

```sh
go test -race ./...
```

Пакет рассчитан на Windows и Unix-платформы. Для `-race` нужен включённый CGO. На Windows требуется C-компилятор с библиотеками MinGW-w64 версии 8 или новее. [Требования детектора гонок Go](https://go.dev/doc/articles/race_detector#Requirements)

Сетевые тесты используют loopback. Для сценариев DNS, таймаутов и отмены тесты подставляют сетевые операции, поэтому им достаточно локальной среды.
